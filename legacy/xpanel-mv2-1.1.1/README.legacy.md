# Archived xPanel 1.1.1

This directory preserves the original Manifest V2 source as migration evidence.
It is intentionally excluded from the xPanel 2.0 build, typecheck, lint, tests,
and packaging. Load this directory itself only when inspecting the historical
extension; its DevTools icon reference was already missing in the original
snapshot.

The historical `.sketch` signing directory and PEM file are not part of this
archive and must never be committed.
